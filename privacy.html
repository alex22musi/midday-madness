Privacy Policy — Muse Health

Last updated: September 21, 2026

Muse Health is a personal-use application built by and for a single individual. It reads the user's own Whoop fitness data (recovery, sleep, strain, and workouts) through the Whoop API and presents it back to that same user through a personal assistant.

  • Data collected: Only the Whoop health data you authorize via Whoop's OAuth consent screen (read-only scopes: recovery, sleep, cycles, workouts, profile, body measurements).
  • How data is used: Solely to show you summaries and analysis of your own data. Nothing is sold, shared, or disclosed to any third party.
  • Data storage: OAuth tokens are stored in a private credential vault; health data is retrieved on demand and not retained beyond the session in which you ask for it.
  • Your control: You can revoke access at any time from your Whoop account settings or the Whoop developer dashboard, which immediately stops all data access.
